I walked this loop on a clear morning before the workshop opened. It climbs
steadily to the ridge, follows it for a while and comes down another way.

The recording is published as a GPX file next to this post. A GPX file holds the
exact positions of the walk, so the build lists this post among those that
publish exact locations.

![A dark ridge against an orange evening sky.](../photos/ridge.jpg "The ridge from the last bend of the path.")

Below the text the post has a map. It shows the track, the download link and
the summary of the walk, and the place where the photo above was taken: this
post publishes the exact position of its photo, because the tag
`trips/mountains` says so. Click the marker to see the photo in full size.
